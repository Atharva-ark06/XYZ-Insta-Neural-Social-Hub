# Security Policy

## Scope

XYZ Insta — Neural Social Hub is a frontend learning prototype. It is not intended to protect real accounts, private media, or sensitive information.

## Supported version

Security work is tracked against the latest code on the default branch and open pull requests.

## Reporting a vulnerability

Please do not publish exploit details, real credentials, private data, or harmful proof-of-concept payloads in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use it. Otherwise, contact the repository maintainer privately through GitHub before creating a public disclosure. Include:
- A concise description and impact
- The affected file or feature
- Reproduction steps using a local test account and non-sensitive data
- Any suggested mitigation

Please allow time for triage before public disclosure. Do not test against accounts, systems, or data you do not own or have explicit permission to assess.

## Security boundaries

Client-side controls are defense-in-depth for a demo, not trusted enforcement. Never submit real passwords or sensitive personal information. See [docs/SECURITY_REVIEW.md](docs/SECURITY_REVIEW.md) and [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
